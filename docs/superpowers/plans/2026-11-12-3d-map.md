# SmartShuttle 3D Map + Mock Buses Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static web demo: a three.js 3D map of the real streets around APU, Bukit Jalil LRT and Parkhill, with simulated buses, growing queues, crowd dispatch, the smart-stop rule and a stop/ETA panel.

**Architecture:** A one-off Node script bakes OpenStreetMap buildings/roads into `src/data/area.json` (local metres, origin at APU). A pure, DOM-free simulation (`src/sim/`) advances buses and queues on a sim clock and is unit-tested. The three.js layer (`src/scene/`) and the panel (`src/ui/`) only read sim state each frame.

**Tech Stack:** Vite 6, three.js 0.170 (OrbitControls from `three/addons`), Vitest 2, plain ES modules (no TypeScript). Node ≥ 20.

**Spec:** `docs/superpowers/specs/2026-11-12-3d-map-design.md`

## Global Constraints
- Project root: `Bus_Buset/smartshuttle-3d/`. All paths below are relative to it.
- No API keys, logins, or network calls at runtime; the built site works offline from `dist/`.
- Show "© OpenStreetMap contributors (ODbL)" on screen.
- Bbox: lat 3.050–3.062, lon 101.688–101.705. Origin (0,0) = APU, lat 3.0553, lon 101.7006. +x = east, +z = south (three.js ground plane), 1 unit = 1 m.
- Stops: `apu` (3.0553, 101.7006), `lrt` Bukit Jalil LRT (3.0583, 101.6922), `parkhill` (3.0561, 101.6957). The fetch script prints the nearest OSM-named feature for each so they can be sanity-checked.
- Bus capacity 40. Bus cruise speed 25 km/h. Dwell at a stop 60 s sim time.
- Sim clock starts 07:00, ends 22:00. Speeds: 1×, 10×, 60× (default 10×).
- Statuses shown exactly as `Ongoing`, `Waiting`, `Offline`.
- Do not push to GitHub; do not commit to main of any remote.

## Review Focus
- Window resized / phone width → canvas and panel must reflow, no horizontal scroll (Task 6 manual check).
- Switching speed to 60× → buses must not skip past stops or overshoot path end (Task 3 test `does not overshoot at large dt`).
- Queue longer than two busloads → dispatch must not spawn unlimited buses; at most one extra bus in flight per stop (Task 4 test `caps extra buses`).
- Clock reaches 22:00 → sim stops cleanly, stops show `Offline` (Task 4 test `offline after service end`).
- Routing can't connect two stops in the road graph → fall back to a straight-line waypoint path instead of crashing (Task 2 test `falls back when disconnected`).

### Task 4: Simulation — queues, timetable, dispatch, smart stop

**Files:**
- Create: `src/sim/arrivals.js`, `src/sim/rules.js`, `src/sim/sim.js`
- Test: `tests/rules.test.js`, `tests/sim.test.js`

**Interfaces:**
- Consumes: Tasks 2–3.
- Produces: `arrivalsPerMinute(stopId, hour) -> number` — `lrt`: 6 at 07–09 and 17–19, 2 otherwise; `parkhill`: 2 at 07–09, 0.5 otherwise; `apu`: 4 at 15–19, 1 otherwise.
- Produces: `shouldStopAtLrt({lrtQueue, nextLrtBusSeats, freeSeats, viaLrtEtaSec, promisedEtaSec}) -> boolean` = all three pitch conditions: `lrtQueue > nextLrtBusSeats && freeSeats > 0 && viaLrtEtaSec <= promisedEtaSec`.
- Produces: `needsExtraBus(queue, capacity, extraInFlight) -> boolean` = `queue > capacity && !extraInFlight`.
- Produces: `createSim({routes, seed}) -> Sim` and `stepSim(sim, dtSec)`. Sim state: `{clock:number /*sec since 00:00*/, running:boolean, stops:{apu,lrt,parkhill:{queue:number}}, buses:Bus[], alerts:[{t, stopId, text}], stats:{boarded:number}}`.
  - Fleet: `L1`, `L2` on the LRT loop (lrt→apu→lrt, departing alternately every 10 min); `P1` on parkhill→apu→parkhill every 20 min.
  - Boarding at a stop: `min(queue, capacity − load)`; alighting at destination empties the bus.
  - Dispatch: when `needsExtraBus` at `lrt`, spawn `X1` from `apu` with `extra:true`, push alert `"Line is longer than one bus: 2nd bus called · arriving in N min"`; remove it after it returns to APU.
  - Smart stop: when `P1` leaves Parkhill, evaluate `shouldStopAtLrt`, with `promisedEtaSec` = via-LRT time × 1.1 (buffer) and `nextLrtBusSeats` = free seats of the next LRT-bound bus; take `parkhill_lrt` + `lrt_apu` if true, else `parkhill_apu`.
  - Queue growth uses a seeded PRNG (mulberry32) so tests are deterministic.
- Produces: `stopScreen(sim, stopId) -> {nextBusMin:number|null, inLine:number, status:'Ongoing'|'Waiting'|'Offline', alert:string|null}` — `Offline` outside 07:00–22:00; `Ongoing` if a bus is driving to or dwelling at this stop; else `Waiting`.

- [ ] **Step 1: Failing tests** `tests/rules.test.js`: `shouldStopAtLrt` true only when all three hold (one case per failing condition); `needsExtraBus(41, 40, false)` true, `(41, 40, true)` false, `(40, 40, false)` false.
- [ ] **Step 2: Failing tests** `tests/sim.test.js`: after stepping 07:00→08:00 in 1 s steps, `stats.boarded > 0` and no stop queue is negative; `caps extra buses` — forcing `lrt.queue = 200` then stepping 10 min yields at most one bus with `extra:true`; `offline after service end` — at clock 22:00 `stopScreen(sim,'lrt').status === 'Offline'` and `running === false`; same seed → identical `stats.boarded` after 1 h.
- [ ] **Step 3: Run** `pnpm test` → FAIL.
- [ ] **Step 4: Implement** the three modules.
- [ ] **Step 5: Run** → PASS.
- [ ] **Step 6: Commit** `feat: queue, timetable, dispatch and smart-stop simulation`.
